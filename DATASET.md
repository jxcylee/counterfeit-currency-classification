# Dataset Attribution

This project uses the Fake Bills Detection Dataset, obtained from Kaggle.

- **Dataset:** [Fake Bills Detection Dataset](https://www.kaggle.com/datasets/imbilal/fake-bills-detection-dataset)
- **Uploader:** imbilal
- **License:** Apache License 2.0

The dataset was used for educational purposes as part of a banknote classification project. Preprocessing included handling missing values and preparing the data for machine learning.

The original dataset is credited to its uploader and remains subject to its original license.
